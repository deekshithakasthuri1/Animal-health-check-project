<strong>Overview</strong>
<p>This is a simple machine learning web application project that predicts whether an animal is healthy or may have a disease based on the symptoms selected by the user.
The project uses a trained ML model and a Flask web interface where users can enter an animal and select symptoms. The model then analyzes the inputs and shows a prediction with a confidence score.</p>
 

<strong>How It Works</strong>
<ol><li>User selects an animal & symptoms</li>
<li>Inputs are converted into model-ready features</li>
<li>The model predicts:
<ul>
  <li>Healthy</li>
  <li>May Have Disease</li>
</ul>
 </li>
<li>Output page shows the prediction + confidence percentage
</li>
</ol>
<strong>Features:</strong> 

<ul><li>Flask backend with easy routing</li>
<li>Confidence score included</li>
<li>Lightweight project structure</li>
<li>Simple and clean UI</li></ul> 

 

<strong>Notes:</strong>
<ul><li>This project uses synthetic data, not real medical data.</li> 
<li>This project uses synthetic data, not real medical data.</li>

</li></ul>
